전주대 대동제 및 해커톤 통합 운영 로그 추출기

정규표현식(re)을 이용해 전주대학교 대동제 및 밤샘 해커톤 통합 운영 로그(log.txt)에서 필요한 데이터를 추출하고, 부스별 매출 합계를 집계하는 파이썬 프로그램입니다.

추출 항목

1. 유효 이메일 추출: 문서 전체에서 올바른 형식의 이메일 주소를 추출하며, 도메인 형식이 손상된 hyunwoo@.ac.kr은 제외합니다.
2. 휴대폰 번호 추출: 010으로 시작하고 중간·끝 각 4자리로 구성된 번호(-, ., 공백 구분자 허용)를 추출하며, 지역번호(063, 02 등)나 자릿수가 맞지 않는 번호는 제외합니다.
3. 재학생 학번과 학과 추출: [학번 / 학과] 표기 중 202로 시작하는 9자리 학번과 학과명을 (학번, 학과) 튜플로 추출합니다.
4. GitHub 저장소 및 2026 유효 쿠폰 추출: gitlab.com을 제외한 github.com 저장소 URL과 FEST-2026-XXXX 형식의 유효 쿠폰 코드를 추출합니다.
5. 부스별 매출 추출 및 합산: 각 부스의 매출: 뒤 금액만 추출해 전체 매출 합계를 계산합니다.

파일 구성

extract_logs.py: 로그 파싱 및 매출 집계 스크립트
log.txt: 운영 로그 데이터
README.md: 프로젝트 설명

실행 방법

python extract_logs.py
