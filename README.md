전주대 대동제 및 해커톤 통합 운영 로그 추출기

이 프로젝트는 파이썬의 정규표현식(re) 모듈을 활용해 전주대학교 대동제와 밤샘 해커톤 통합 운영 로그(log.txt)에서 필요한 정보를 자동으로 뽑아내고, 부스별 매출과 전체 매출 합계를 계산하는 프로그램입니다.

프로그램 동작 방식

log.txt 파일을 UTF-8 인코딩으로 읽어온 뒤, 5가지 항목별로 정해진 패턴에 맞는 문자열을 찾습니다. 문자열 형태로 뽑힌 매출 금액은 쉼표를 제거한 뒤 정수로 변환해 리스트로 모으고, sum() 함수로 전체 매출 합계를 구합니다.

항목별 추출 기준과 제외 대상

유효 이메일 추출: 공백이 없는 이메일 형식 문자열을 찾아내고, 도메인 앞부분이 비어 손상된 hyunwoo@.ac.kr 같은 잘못된 주소는 제외합니다.

휴대폰 번호 추출: 010으로 시작하고 가운데와 끝 자리가 각각 네 자리 숫자인 번호를 추출합니다. 구분자로 하이픈(-), 마침표(.), 공백을 허용하며, 063 같은 지역번호나 자릿수가 맞지 않는 번호는 걸러냅니다.

재학생 학번과 학과 추출: 대괄호 안에 적힌 [학번 / 학과] 형태 중 202로 시작하는 아홉 자리 학번과 슬래시 뒤의 학과명을 (학번, 학과) 튜플로 묶어 추출합니다.

GitHub 저장소 및 2026 유효 쿠폰 추출: http 또는 https로 시작하는 github.com 저장소 주소만 골라내어 gitlab.com 주소를 제외하고, FEST-2026-으로 시작하는 유효 쿠폰 코드를 함께 추출합니다.

부스별 매출 추출 및 합산: 로그 안에서 매출: 뒤에 이어지는 금액만 찾아 부스별 매출 목록을 만들고, 이를 모두 더해 총 매출 합계를 출력합니다.

파일 구성 및 역할

extract_logs.py: log.txt를 읽고 정규표현식으로 데이터를 추출한 뒤 매출 합계와 결과를 터미널에 출력하는 메인 스크립트입니다.
log.txt: 대동제 및 해커톤 운영 기록이 담긴 원본 로그 데이터 파일입니다.
README.md: 프로젝트 목적, 추출 기준, 실행 방법과 결과를 정리한 안내 문서입니다.
